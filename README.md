# GuardianCare - Smart Medication & Caregiver Tracking App

GuardianCare is a cross-platform healthcare application built with Flutter designed to improve medication adherence and bridge communication between patients and their caregivers.

Developed as part of the CS 464: Human-Computer Interaction (HCI) course at the Computer and Information Technology Department.

---

## Key Features
- Dual User Roles: Customized interfaces for both Patients and Caregivers.
- Medication Scheduling: Track daily doses (After Breakfast, Lunch, Dinner) with status toggles (Pending / Taken).
- Pill Verification: Built-in safety check to ensure correct medication intake.
- Caregiver Dashboard: Real-time monitoring and progress tracking for caregivers.
- Multi-language Support: Full localization for English, Spanish, and Arabic.
- System Alerts: Missed dose tracking and notification management.

---

## Tech Stack & Architecture
- Frontend: Flutter (Dart)
- Backend: PHP Scripts
- Database: MySQL / MariaDB (XAMPP local server)
- Design & Prototyping: Figma

---

## Usability Testing & HCI Insights
We conducted a moderated usability testing session with 10 participants to evaluate the UI/UX performance:
- 90% of participants found the application purpose clear and easy to navigate.
- 100% positive response regarding interface simplicity.
- 100% found the caregiver feature intuitive and effective.
- 90% stated they would use the app in the future.
